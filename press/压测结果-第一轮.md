## 2. 关键发现

### 2.1 tp4 单副本全部早早饱和

所有 tp4 dp=1 部署在 RPS 2 即饱和(RPS4 时实测仅 1.2~1.9): BF16 吞吐天花板 146 tok/s,fp8 158,w4a16 系 168,nvfp4 系 ~227。pc agent 长 prompt(~3.7k tokens 含图)使 prefill 成为瓶颈。

### 2.2 nvfp4(Blackwell FP4 内核)同形态下显著最快

tp4 下 nvfp4-w4a4 比 gptq-w4a16 快 **36%**(229 vs 168 tok/s),轻载 E2E 2.28s vs 2.88s。两个 nvfp4 变体(RTN 与 GPTQ 版)性能几乎一致。

### 2.3 4bit 模型部署形态收益巨大(本实验最重要结论)

| 形态 | nvfp4-w4a4 吞吐 | 实测 RPS | E2E p95 |
|---|---|---|---|
| tp4 dp1 | 229 tok/s | 1.86 | 72.7s |
| tp2 dp2 | 369 tok/s | 3.03 | 29.6s |
| **tp1 dp4** | **474 tok/s** | **3.77** | **7.8s** |

4bit 权重量化后单卡可放完整模型,**dp4 纯数据并行效率碾压 tp**——dp1tp4 相比 tp4 吞吐 2.07 倍,且 RPS4 接近满速率(3.77/4),E2E p95 从 73s 降到 8s。w4a16 系同规律(168→237→293 tok/s)但绝对值低一档。

### 2.4 最优组合

**nvfp4-w4a4 或 gptq-nvfp4 + dp1tp4**: ~470/456 tok/s,RPS4 下 E2E 均值 3.0s / p95 6.3~7.8s。
相比 BF16 tp4 基线(146 tok/s, RPS4 已打爆 E2E p95 139s): **吞吐 3.2 倍**。

## 3. 与一致性评估联合选型

(对照 `../eval/评估结果-第一轮.md`,L0/L1/L2 为对 BF16 同栈参照的一致率)

| 方案 | 一致性 L0/L1/L2 | 最优形态吞吐(RPS4) | 综合 |
|---|---|---|---|
| fp8-w8a8 | **47.9 / 74.6 / 86.6** | 158(tp4)→ 219 tok/s(dp2tp2) | 一致性最好,性能中 |
| awq-w4a16 | 37.0 / 67.0 / 79.8 | 295 tok/s (dp4) | 平衡 |
| gptq-nvfp4 | 33.3 / 61.8 / 81.2 | 456 tok/s (dp4) | 性能优,一致性中 |
| nvfp4-w4a4 | 27.9 / 58.1 / 79.5 | **474 tok/s (dp4)** | 性能最强,一致性最弱 |
| gptq-w4a16 | 32.5 / 61.5 / 75.8 | 293 tok/s (dp4) | 可解析率 93.3% 需警惕 |
| smoothquant-w8a8 | 不可部署(sm120 无 int8 内核) | — | 出局 |

**建议**:
- 一致性优先(线上行为敏感): **fp8-w8a8**,dp2tp2 下 219 tok/s(仍不到 nvfp4+dp4 的一半),或加副本扩展
- 性能优先且能接受行为漂移: **nvfp4 系 + dp4**,注意其 L0 净漂移 -43~-48pp
- 折中: awq-w4a16 + dp4
