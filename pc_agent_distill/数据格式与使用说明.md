## 二、字段格式

### 2.1 转换样本（agentnet_*_pcagent.jsonl）

```jsonc
{
  // ---- 标识与元信息 ----
  "sample_id": "20240927..._s3_0",   // 主键：{task_id}_s{step_index}_{sub_index}
  "task_id": "20240927...",          // AgentNet 原始任务 ID
  "system": "Windows",               // Windows / Darwin（ubuntu 集为 Linux）
  "domain": "Office Tools",
  "instruction": "sort the table ...",       // 任务指令（拼进 prompt 用的）
  "natural_language_task": "Could you help me ...",  // 口语化版本（未使用，备用）

  // ---- 步信息 ----
  "step_index": 3,                   // 轨迹中的第几步（0 起）
  "sub_index": 0,                    // 原 step 的多行 pyautogui 代码拆成多个原子动作时的序号
  "is_continuation": false,          // sub_index > 0 时为 true

  // ---- 图片 ----
  "image": "win_mac_images/<uuid>.png",       // 逻辑文件名（散文件不存在！）
  "image_tar": ["shard_0007.tar", 123456, 375231],  // ★ 真实读取方式：[分片名, 字节偏移, 字节数]
  "image_width": 1280, "image_height": 720,   // 图片真实像素尺寸

  // ---- 训练核心 ----
  "prompt": "### Background ###\nThis image is ...",   // PC-Agent 决策提示词全文
  "response": "```json\n{\"Thought\": ..., \"Action\": \"Tap (163, 271)\", \"Summary\": ...}\n```",  // AgentNet GT（PC-Agent 格式）
  "messages": [                      // OpenAI 多模态 chat 格式，可直接用于 SFT
    {"role": "system", "content": "You are a helpful AI PC operating assistant. ..."},
    {"role": "user", "content": [
      {"type": "text", "text": "<prompt 全文>"},
      {"type": "image", "image": "win_mac_images/<uuid>.png"}   // 训练前需替换为图片实体
    ]},
    {"role": "assistant", "content": "<response>"}
  ],

  // ---- 坐标（两套） ----
  "coord_format": "normalized_0_999",  // response/action 里用 [0,999] 归一化坐标
  "action": "Tap (163, 271)",          // 归一化坐标版本（= response 里的 Action）
  "action_pixel": "Tap (235, 244)",    // 像素坐标版本（相对图片真实尺寸）

  // ---- 质量标签（AgentNet 原始标注，用于过滤） ----
  "gt_action 相关": "...",
  "observation": "...",                // 当步截图的文本观察（未进 response）
  "raw_code": "pyautogui.click(x=0.1632, y=0.2711)",  // AgentNet 原始动作代码
  "reflection_of_this_step": "...",    // 对本步的事后评判
  "this_step_correct": true,           // 本步动作是否正确
  "this_step_redundant": false,        // 本步是否冗余
  "task_completed": false,             // 整条轨迹最终是否成功
  "terminated_with_fail": false,       // 该 Stop 是否实为失败终止
  "alignment_score": 7, "efficiency_score": 6, "task_difficulty": 3
}
```

### 2.2 蒸馏输出（distill_*_dedup.jsonl）

```jsonc
{
  "sample_id": "...",              // join 键，对应转换样本的 sample_id
  "model_output": "{\"Thought\": ...}",   // GUI-Owl-32B 原始输出文本
  "model_thought": "...",          // 解析出的 Thought
  "model_action": "Tap (52, 278)", // 解析出的 Action
  "model_summary": "...",          // 解析出的 Summary
  "parse_ok": true,                // JSON 解析是否成功（失败的进不了模型输出三字段）
  "gt_action": "Tap (48, 289)",    // 对应的 AgentNet GT（评估对照用）
  "prompt_tokens": 1863,
  "completion_tokens": 88,
  "latency_s": 23.2
}
```

## 三、Prompt 是怎么组装的

prompt 由 PC-Agent 源码 `PCAgent/prompt_qwen.py` 的 `get_action_prompt()` 原样生成（转换脚本直接 import 该函数），各段落按顺序拼接：

```
### Background ###
This image is a computer screenshot where icons are marked with numbers.
Its width is {image_width} pixels and its height is {image_height} pixels.
The user's instruction is: {instruction}.

### Screenshot information ###        ← 本数据集为空（AgentNet 无 OCR/a11y 标注）
                                        因此走"纯视觉"分支，prompt 里声明：
                                        坐标使用 [0,999] 归一化（左上 (0,0)，右下 (999,999)）

### History operations ###            ← 轨迹前序步骤，逐步累加：
Step-1: [Operation: {summary}; Action: {action}; Reflection: {reflection}]
Step-2: [...]

### Last operation ###                ← 仅当上一步被标注 last_step_correct=false 时注入：
"You previously wanted to ... But you find that this operation does not
meet your expectation. You need to reflect and revise your operation this time."

### Task requirements ###             ← 动作空间定义（12 个动作的自然语言说明）：
Right Tap (x, y) / Tap (x, y) / Double Tap (x, y) / Shortcut (key1, key2) /
Press (key) / Type (x, y), (text) / Select (content) / Replace (x, y), (text) /
Append (x, y), (text) / Tell (answer) / Stop

### Output format ###
要求输出 {"Thought": ..., "Action": ..., "Summary": ...} JSON，一次一个动作
```

**关键约定**：
- 坐标一律 **[0,999] 归一化**——与 PC-Agent `run.py` 执行时的反归一化（`x * width / 1000`）完全兼容
- system prompt 固定为 PC-Agent 决策模块原文：
  `"You are a helpful AI PC operating assistant. You need to help me operate the PC to complete the user's instruction."`
- 不使用任何 tools / function calling API——动作空间纯 prompt 定义，输出靠文本解析
- AgentNet → PC-Agent 动作映射：click→Tap、doubleClick→Double Tap、rightClick→Right Tap、write→Type、hotkey→Shortcut、press→Press、terminate→Stop；Drag/Scroll/HScroll/Middle Tap 为扩展动作（约 10%，PC-Agent 原生动作空间没有）

## 四、图片加载方法

截图不散存（JuiceFS 小文件创建太慢），全部打包在 tar 分片中，用索引随机读：

```python
import json, base64, io
from PIL import Image

BASE = '/mnt/lisiqi23/internship/zhangyikang/uiagent/pc_agent_distill'

class TarImageLoader:
    """按 image_tar=[shard, offset, size] 随机读取截图。句柄缓存，可复用。"""
    def __init__(self, tar_dir):
        self.tar_dir = tar_dir
        self.handles = {}

    def load_bytes(self, image_tar):
        shard, off, size = image_tar
        if shard not in self.handles:
            self.handles[shard] = open(f'{self.tar_dir}/{shard}', 'rb')
        f = self.handles[shard]
        f.seek(off)
        return f.read(size)

    def load_pil(self, image_tar):
        return Image.open(io.BytesIO(self.load_bytes(image_tar)))

    def load_b64(self, image_tar):
        return base64.b64encode(self.load_bytes(image_tar)).decode()

# win/mac 和 ubuntu 各用一个 loader
wm_loader = TarImageLoader(f'{BASE}/win_mac_tar')
ub_loader = TarImageLoader(f'{BASE}/ubuntu_tar')
```

## 五、组装最终 SFT 训练数据

蒸馏文件只有模型回答，训练样本需要 join 回完整输入。完整示例：

```python
import json

BASE = '/mnt/lisiqi23/internship/zhangyikang/uiagent/pc_agent_distill'

def assemble(converted_path, distill_path, out_path, min_quality=True):
    # 1. 载入蒸馏输出
    distill = {}
    with open(distill_path) as f:
        for line in f:
            r = json.loads(line)
            if r.get('parse_ok'):
                distill[r['sample_id']] = r

    # 2. join 回完整样本，assistant 回答换成蒸馏输出
    n_in, n_out = 0, 0
    with open(converted_path) as fin, open(out_path, 'w') as fout:
        for line in fin:
            d = json.loads(line)
            n_in += 1
            r = distill.get(d['sample_id'])
            if r is None:
                continue
            if min_quality:
                # 常用过滤：只保留 GT 标注为正确、且轨迹最终成功的样本
                if not d.get('this_step_correct') or not d.get('task_completed'):
                    continue
                if d.get('terminated_with_fail'):
                    continue

            resp = r['model_output'].strip()
            if not resp.startswith('```'):
                resp = '```json\n' + resp + '\n```'   # 统一围栏，对齐 PC-Agent 解析习惯
            d['messages'][-1] = {"role": "assistant", "content": resp}
            d['response'] = resp
            d['thought'] = r['model_thought']
            d['action'] = r['model_action']
            d['summary'] = r['model_summary']
            fout.write(json.dumps(d, ensure_ascii=False) + '\n')
            n_out += 1
    print(f'{out_path}: {n_out}/{n_in} samples kept')

assemble(f'{BASE}/agentnet_win_mac_pcagent.jsonl',
         f'{BASE}/distill_32b_dedup.jsonl',
         f'{BASE}/sft_win_mac.jsonl')
assemble(f'{BASE}/agentnet_ubuntu_5k_pcagent.jsonl',
         f'{BASE}/distill_ubuntu_32b_dedup.jsonl',
         f'{BASE}/sft_ubuntu.jsonl')
```

**训练时 messages 里的图片字段**是逻辑路径占位，dataloader 里需用 `TarImageLoader`
按 `image_tar` 字段读真实图片（或在 assemble 阶段直接展开成 base64/本地路径，视训练框架而定）。

### 可选过滤条件（按训练目标选用）

| 条件 | 字段 | 说明 |
|---|---|---|
| 解析成功 | 蒸馏侧 `parse_ok == true` | 默认已过滤（~2.8% 被去掉） |
| GT 步骤正确 | `this_step_correct == true` | 去掉 AgentNet 标注的错误步 |
| 轨迹最终成功 | `task_completed == true` | 失败轨迹的答案参考价值低 |
| 非失败终止 | `terminated_with_fail == false` | 86 条（Stop 实为 fail） |
| 去掉扩展动作 | `action` 不含 Drag/Scroll/HScroll/Middle Tap | 若要严格对齐 PC-Agent 原生动作空间 |
| 去掉续拆子步 | `is_continuation == false` | 这些样本的 thought 是模板句（"Following the plan..."） |
| 难度分层 | `task_difficulty` 1~5 | 课程学习可用 |

## 六、已知注意事项

1. **坐标是归一化的**：response 里 `Tap (163, 271)` 是 [0,999] 空间，不是像素。
   需要像素时用 `action_pixel` 字段（基于图片真实尺寸计算）。
2. **图片真实尺寸 ≠ meta 标称分辨率**：98.5% 的任务截图被 AgentNet 缩放过
   （如标称 1920×1080 实际 1280×720）。prompt 声明的尺寸、`action_pixel` 均已按真实尺寸修正。
3. **win/mac 输入有重复**：AgentNet 有 93 个 task_id 重复出现 → 5,370 行重复样本。
   蒸馏输出已按 sample_id 去重；若 SFT 不想去重可保持现状，反之按 sample_id distinct 即可。
4. **Stop 的语义**：`terminated_with_fail=true` 的 Stop 是任务失败终止（86 条），建议过滤。
5. **Type 无坐标变体**：少数样本为 `Type ("text")`（轨迹中没有前置点击坐标可推断），属正常格式。
